Сені тыңдауға орын бар.

Кейде ойыңды бөлісудің өзі — алғашқы қадам. Сезімдеріңді түсінуге және өзіңе жайлы шағын қадам табуға уақыт бөл.

Aig көмек — жалпы эмоциялық қолдау. ЖИ қателесуі мүмкін. Ол психологты алмастырмайды, диагноз қоймайды және ем тағайындамайды.

Егер өзіңе зиян келтіру қаупі болса немесе біреу қауіп төндірсе, жергілікті жедел көмек қызметіне дереу хабарлас не қасыңдағы қауіпсіз адамнан көмек сұра. Мүмкін болса, сенімді адамның жанында бол және өзіңе зиян келтіруге болатын заттардан алыста. Көмек алу үшін чат жауабын күтудің қажеті жоқ.

Қосылым тексерілуде…

ЖИ қосылымы · осы терезеде

HTML файлын тікелей ашқанда да істейді. Жаңа Chrome/Edge, WebGPU және шамамен 1 ГБ бос графикалық жад қажет. Телефондар мен басқа браузерлердегі қолдау әртүрлі.

Алғаш іске қосқанда интернеттен шамамен 300 МБ жүктеледі. Qwen2.5 0.5B моделі браузер қоймасында сақталады; браузер оны өшірсе, қайта жүктеу қажет.

Жеке қолдануға арналған: кілт осы беттің жадында ғана болады, HTML-ге жазылмайды. Ортақ кілтті келушілерге таратпа. OpenAI API бөлек төленеді; ChatGPT жазылымына кірмейді.

Бұрынғы Node.js серверімен жұмыс істейтін сайтқа арналған. Сайт мекенжайын ашып, сервердегі OpenAI кілтін бапта. Бөлек HTML файлы үшін басқа режимді таңда.

Режимді ауыстырғанда диалог өшеді. Барлық басқару осы чатта қалады.
